## 双开管家 v2.0.4

Android TV 端应用双开：对着已安装的应用点一下「双开」，**在本机现场重打包并安装出第二份**。
不需要 root、不需要电脑、不联网。

### 本次更新

- 焦点态重做：未选中为深色底浅色字，选中为近白底 + 3dp 蓝色描边 + 深色字。
  之前两种状态都是蓝色，电视上无法分辨焦点位置。
- 整行焦点同步加强（底色提亮 + 3dp 蓝边）。

### 安装

```bash
adb install -r TvDualManager-v2.0.4.apk
```

或拷到 U 盘，用电视自带文件管理器安装（需允许「未知来源」）。

**系统要求：Android 7.0 及以上**（克隆包只带 v2 签名，5.x / 6.x 装不上）。

### 使用

1. 打开「双开管家」，主界面是已安装应用列表
2. 焦点移到目标应用右侧的「双开」，按 OK
3. 等系统安装确认，完成后回桌面会多出「应用名 ①」

### 已知限制

- 分卷安装的应用（App Bundle 拆包）不支持
- 加固壳 / 支付 / 微信登录 / DRM 片源类应用，克隆后失效或闪退（签名变了）
- 克隆包与原版签名不同，只能共存，不能覆盖升级原版

### 校验

```
SHA-256  见附件校验值
签名      v1+v2+v3，证书 CN=TvDual
minSdk    24    targetSdk 33
```
